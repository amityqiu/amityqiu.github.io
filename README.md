# 怎么改网站内容

网站的字都在 content 文件夹里，一本书一个文件：
box.md 礼盒　expo.md 巡展　early.md 习作　articles.md 文章　research.md 研究
首页两段自我介绍在 home.md。
改法：在 GitHub 里点开文件，右上角铅笔，改完点 Commit changes，等两分钟刷新网站。

## 写法（就这几种）

# 大标题　　　　一行开头一个井号加空格，是这本书的名字，每个文件只写一个
## 小标题　　　　两个井号加空格
> 灰色小字　　　大于号加空格，用来放时间、单位、角色这类信息，一般紧跟在大标题下面
- 列表　　　　　短横加空格，一行一条
普通行就是正文，空一行分段。
**加粗**　　　　两边各两个星号
[文字](网址)　　方括号里是显示的字，圆括号里是链接，点文字就跳过去

## 放图
1. 把图传到 images 文件夹（先压一下，长边两千像素左右）
2. 在 .md 里单独写一行文件名，比如　礼盒实物.jpg
3. 想加说明就在后面加竖线，比如　box-1.jpg | 新年礼盒实物
4. 想让一张图占两格，再加一个竖线写「宽」，比如　box-1.jpg | 新年礼盒实物 | 宽
连着写几行图片，会自动排成三列的图墙，统一裁成 4:3，点开看全图。

## 照片和随心记
照片：传到 photos 文件夹就行，不用改任何文件，按文件名倒序排。
随心记：改 notes.md，第一行日期，下面写内容，条与条之间空一行。

## 不要动的
index.html 是网页本身，不用改。图片和照片的文件名尽量用英文或数字，中文名在有些电脑上会变乱码。书脊、封面上的字和鼠标滑过的那几句在里面，要改找 Claude。

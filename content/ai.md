# AI 实践：零代码，但东西都做出来了
> 2026　工作里用、生活里用、自己动手做

我不会写代码。下面这些东西都是我和 AI 一起做出来的：我负责想清楚要什么、把需求说明白、测试、改方向，AI 负责写代码。它们都在用。

## 这个网站
就是你现在看的这个。书架、翻书、相机、本子，从设计到实现全部和 Claude 一起完成，没有用任何模板。内容不在代码里，在一堆 Markdown 文件里，我在 GitHub 网页上改一行字、传一张图，两分钟后网站自己更新，不用再找任何人。
- 源码公开在 [github.com/amityqiu/amityqiu.github.io](https://github.com/amityqiu/amityqiu.github.io)

## 物品胶囊：一个记东西的微信小程序
搬家前想知道自己到底有多少东西、哪些该扔、哪些快用完了。市面上的记账软件记的是钱，我要记的是物。于是做了一个：记录每一件东西和它的来处（买的、谁送的），有在用、用完、闲置、送出、丢弃的状态流转，算得出一件东西陪了我多少天、每天合多少钱，用完的时候会问一句「还买吗」。
- 微信云开发，体验版在用
- 【仓库链接，传上 GitHub 后填】

## 秋招筛选工具（搭建中）
秋招每天几百个岗位，看不过来。在搭一个每天自动筛的小工具：按届别、城市、岗位方向过滤，标出需要先做测评的公司，筛完的结果推到飞书群里，投递记录接回我自己的飞书多维表格。只做筛选，不做自动投递。
- Python + 飞书 API

## 工作里怎么用
在 Meshy 做雇主品牌，AI Agent 是日常工具：需求拆解、信息汇总、竞品对标的资料整理和报告产出、中英双语稿的互译校对。对标研究那份案例库的采集 SOP，也是和 AI 一起定的。图片侧用 Midjourney 和即梦出概念图，排版用 Figma、Canva 和 SVG。

## 我的理解
AI 没有把我变成程序员，它把「想清楚」变成了最值钱的能力。需求说得越准，做出来的东西越对。这件事在做内容和做产品上是一样的。
